
📒 Contact Book CLI App

A simple Python Command-Line Contact Book where you can add, search, update, and delete contacts (including address) right from your terminal.
Perfect for beginners who want to practice Python, file handling, and CLI applications.


---

✨ Features

➕ Add a new contact (name, phone, email, address)

🔍 Search for a contact by name or phone

✏️ View all saved contact

❌ Delete a contact

✏️ Update contact's phone number

💾 All contacts are saved locally in a JSON file (so your data persists)



---

🚀 Getting Started

1️⃣ Clone the repository

git clone https://github.com/6lackRaven/Contact.git
cd Contact

2️⃣ Run the app

python main.py


---

🛠️ Requirements

Python 3.7+
(No extra libraries needed – everything is built-in!)
